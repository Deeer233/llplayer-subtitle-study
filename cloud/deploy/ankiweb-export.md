# LLPlayer 原声卡：加入 Anki 与手机复习

1. **首次**：在桌面 Anki 的「工具 → 附加组件 → 获取附加组件」输入 `2055492159` 安装 AnkiConnect。重启 Anki，打开要用的配置。打开 Anki 版联调包，在「私人词本 → Anki 连接」点「连接桌面 Anki」，绑定当前配置。
2. **平时**：播放本地视频，左键点英文字幕里的词 → 点「核对原声词卡」→ 填「本句义」→ 点「截取并试听」→ 听完点「确认并加入 Anki」。不用手动选卡、拷 MP3 或导入 TSV。
3. **Anki 没开**：合格原声先在本机排队。打开桌面 Anki 的原绑定配置后，运行中的 LLPlayer 会自动补写。
4. **手机复习前**：确认卡片已在桌面 Anki，且有权上传。手动点桌面 Anki 的「同步」，等媒体同步完成，再用手机浏览器登录 AnkiWeb 复习。

## 已有原声与本地词表

启动或绑定不会自动批量加入旧卡。要加入已有原声，在「Anki 连接」手动点一次「自动加入已有原声」，授权本次筛选并排队。每个义项只选一段已核对、已入本的合格原声；已有写入任务的义项不重复排队。未核对、已撤回的原声和文字词表不加入。

「本地词表」只在本机保存文字，不上送原站点，不生成原声卡，不写入 Anki，也不随此流程同步到 AnkiWeb。

## 状态与兼容范围

- 「未连接桌面 Anki」表示尚未绑定；「已绑定桌面 Anki」不代表 Anki 当前在线。绑定后可点「检查 Anki 连接」。切换了 Anki 配置就切回原配置，不能用这个按钮换绑。
- 「待写入」表示仍在本机等候。出现「需处理」时，按提示处理后点「重试待处理卡」。「已写入」只表示桌面任务完成，不表示 AnkiWeb 或媒体已同步。LLPlayer 不触发同步，也不读取同步结果。
- 自动写入只适用于本地词本的 Anki 版联调包，不走原站点配对流程。只连接本机 `127.0.0.1:8765`，使用 AnkiConnect API v6。附加组件须支持 `getActiveProfile`、`findModelsByName` 等所需接口，并允许不带 API Key 的本机调用。手机端不是写入目标。
- 新增笔记使用「LLPlayer 原声复习」牌组和「LLPlayer 原声 v1」笔记类型。按 `libraryId:cardId` 匹配，不按拼写合并。旧 TSV 导入的笔记若只有一条同 ID 记录，且笔记类型、六字段顺序及单张卡片的正背模板匹配，可原位更新字段。重复 ID 或模板不兼容会停止写入，不改现有模板。

修正同一义项时，不勾「改归其他义项，不更新原 Anki 卡」，保留原卡 ID。撤回会取消该义项的待写入任务，不会自动删除或暂停已写入的卡。需要时在「已撤回卡：在 Anki 暂停」复制查询条件，到桌面 Anki 浏览器手动暂停。

只处理合格的短原声和卡片字段，不传整集、完整字幕或原文件路径。整句中文仅保存在本机，不写入 Anki；不要在台词或出处填入本地路径。

<summary>备用：手动导出到 Anki（TSV + MP3）</summary>

仅在不能自动写入时使用。

1. 在「Anki 连接」展开「备用：手动导出到 Anki」。按住 Ctrl 可多选已核对的原声卡，同一义项只选一段。
2. 点「导出所选卡片…」，选本地上级文件夹。导出的子目录包含 `cards.tsv`、`media/` 和 `Anki导入说明.txt`。
3. 按导入说明创建或复用兼容的「LLPlayer 原声 v1」笔记类型，将 MP3 复制到当前配置的 `collection.media`。导入 TSV 时按 ID、音频、表达、本句义、英文原句、出处映射，允许 HTML。已有笔记选「更新」，匹配范围选「笔记类型」，不要导入为新笔记。
4. 在桌面检查正面能播放原声，翻面可见表达、本句义、英文原句和出处，再按顶部步骤手动同步。

本地文件已导出，不等于桌面 Anki 已导入或 AnkiWeb 已同步。备用导出不直接写入 Anki，不读取手动导入结果，也不迁移复习记录。
