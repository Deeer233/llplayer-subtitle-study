# 原声单词复习

这是独立的 Windows 工具。它不读取播放器数据，也不自动从播放器入本。

## 导入词表

- TXT：每行一个词或短语。只有单词时也能导入；词库里的「批量补词典义」可给无例句的待补卡填入本地词典参考，确认后即可做文字复习。
- CSV / TSV：无表头时按「单词、释义、英文例句、整句中文」的顺序。后三项可空。有表头时可调整列顺序；参照 `sample-words.csv`。
- 支持 UTF-8、带 BOM 的 Unicode 文本。文件上限 4 MB。导入有预览，无效行会标出；已经存在的相同表达、释义和英文例句会跳过。同形异义保留为不同卡片。
- 批量补义不覆盖已有释义，不处理有例句或原声的卡。词典查不到的词仍可手填。编辑单张卡时可点「查本地词典」对照，查询结果不会自动当作本句义写入。词典及其许可证随包附带，无网络请求。
- 导入的词是文字卡，不当作原声题。要做原声卡，在「词库 → 新增」填英文原句和本句义，选已剪好的 WAV、MP3 或 M4A 片段，核对后勾选一致。工具复制片段，不改原文件。

## 同一词义的备选原声

- 在词库选中原声卡，点「加备选原声」。填另一句英文和可选的中文，选择并试听片段，核对原句与原声、词义一致后保存。不同词义用不同卡，不自动合并。
- 补例句不改已定的复习日期或成绩。当天重试继续听刚才的句子；下次到期改用另一句。某个本地副本缺失时会尝试另一句。
- 移除有多条例句的卡只移除词库记录，保留音频副本。新版能读取旧卡；新增备选后继续用新版，旧版保存时不会保留新字段。

## 需要手动验收

1. 打开发布包里的 `OriginalReview.exe`。如果之前的测试窗口还开着，先关闭它。这两个窗口不能同时打开。
2. 点「导入词表」，选 `sample-words.csv`，确认。词库应新增 4 张；再次导入应新增 0 张、跳过 4 张。
3. 回到「今日复习」：应有 3 张文字卡、1 张待补释义。到「词库 → 批量补词典义」并确认，`walk away` 应变成标着「词典义」的文字卡，今日文字卡变为 4 张。再次导入不应新增卡片。复习揭晓前只显示表达；关闭再打开，卡片仍在。
4. 用已听校的片段新增一张原声卡，再选中它点「加备选原声」，添另一条同义例句。词库应显示「原声 · 2 句」。点「开始原声复习」，应先听音频，音频播完可揭晓，显示刚才播放的那句。点「没想起」并在当天重试，应再播同一句；下一次到期应换句。

默认数据在 `%LOCALAPPDATA%\OriginalReview`。移动程序时保留整个发布目录。工作区测试命令：`pwsh -NoProfile -File .\review\check-review.ps1`；发布命令：`pwsh -NoProfile -File .\review\publish-review.ps1`。
